# 제주 문화달력 (Vite + React)

제주도민과 관광객을 위한 **제주 문화행사 안내 웹사이트**입니다.
제주특별자치도 「전시문화행사정보」 OpenAPI(제주in놀다)의 실데이터에 날씨·지도·관광지·지역축제·AI 가이드를 더했고, 한국어·영어·중국어·일본어로 볼 수 있습니다.

- 프런트엔드: Vite 8 · React 19 · react-router-dom 7 · Zustand 5 · Leaflet (UI 라이브러리 없이 직접 만든 CSS)
- 서버: Vercel 서버 함수(`api/`) — API 키를 보관하고 외부 서버를 대신 호출합니다
- 배포: Vercel (GitHub `main` 에 push 하면 자동 배포)

## 빠른 시작

```bash
npm install
cp .env.example .env.local   # 키를 채웁니다 (없어도 행사·날씨·지역축제는 동작)
npm run dev                  # http://localhost:5173
npm run build                # 배포용 빌드
npm run preview              # 빌드 결과 확인
```

`npm run dev` 와 `preview` 는 `vite.config.js` 의 플러그인이 `api/` 의 서버 함수를 그대로 실행해 줍니다. 그래서 로컬과 배포가 같은 코드로 동작합니다. 환경변수를 바꾸면 개발 서버를 껐다 켜야 반영됩니다.

### 환경변수

| 이름 | 용도 | 없으면 |
|---|---|---|
| `VISITJEJU_API_KEY` | 비짓제주 관광정보 (주변 가볼 만한 곳) | 관광지 부분에만 안내 문구가 뜨고 나머지는 정상 |
| `ANTHROPIC_API_KEY` | AI 가이드 (Claude) | 대화창에 "아직 준비되지 않았어요" 표시 |
| `ANTHROPIC_MODEL` | (선택) AI 가이드 모델. 기본 `claude-opus-5-5` | 기본값 사용 |

- **`VITE_` 를 붙이지 마세요.** 붙이면 브라우저 코드에 키가 노출됩니다. 키는 서버 함수에서만 읽습니다.
- Vercel: Project Settings → Environment Variables 에 추가한 뒤 **재배포**해야 반영됩니다.
- 로컬: `.env.local` (git 에 올라가지 않습니다)

### 행사 API 명세와 실제 응답이 다른 점
- **CORS 헤더가 없어** 브라우저가 직접 부를 수 없습니다 → 서버 함수가 대신 호출합니다 (허용한 파라미터만 전달).
- 상세 응답의 키가 명세서에는 `event`, 실제로는 **`evnet`(오타)** 입니다. 둘 다 처리합니다.
- 좌표 `x`,`y` 가 0 이거나 위도·경도가 뒤바뀐 데이터가 있어 제주 범위 안일 때만 지도에 씁니다.
- `intro` 는 HTML 이거나 평문이라 글자만 뽑아 보여줍니다. 분류 이름의 `(사용안함)` 같은 덧붙임은 정리합니다.
- 명세서의 `with` 필터는 동작하지 않아 쓰지 않았습니다. 현재 약 120건이라 한 번에 받아 화면에서 거릅니다.
- 날짜는 모두 한국 시간(KST) 기준 `YYYY-MM-DD` 문자열로 다룹니다 (문자열 비교가 곧 날짜 순서).

### 비짓제주 관광정보의 특징과 정리 규칙
- 응답에 **시작일·종료일이 없어** 달력·기간 검색에는 쓸 수 없고, 위치 정보로만 씁니다. 약 2,500건(음식점 1,285 · 행사 686 · 관광지 524 · 숙박 · 쇼핑 등)이고 언어별로 항목 수가 조금씩 다릅니다.
- 서버 함수가 지도·주변 추천에는 **"관광지" 분류만** 내려줍니다 (음식점·숙박·쇼핑·행사는 제외).
- 관광지 안에서도 동물병원·애견미용실·병원·헬스장·렌터카 같은 **생활 서비스 업소**와 다이빙·서핑·승마·공방 수업·스파·골프장 같은 **상업 업체**는 뺍니다. 기준과 목록은 `api/_unrelated.js`, `api/_exclude.js` 에 있고, 태그는 언어마다 번역돼 있어서 규칙도 언어별로 따로 둡니다.
- 좌표가 비어 있는 항목에 원본이 **제주시 한복판(33.4996, 126.5312)을 기본값으로 채워 둔 경우**가 있어(서귀포 중문의 신사터가 제주시에 찍힘) 위치를 믿을 수 없는 항목은 뺍니다.
- 제거할 항목이 더 보이면 `api/_exclude.js` 에 항목 번호를 추가하거나 `_unrelated.js` 의 규칙을 고칩니다.
- 네이버 지도 검색어는 `시 + 이름` (예: "서귀포시 생약누리") 순서로 만듭니다. 길거나 뒤에 덧붙임이 있으면 검색이 안 됩니다. 영어·중국어·일본어는 좌표로 구글 지도를 엽니다.
- 서버 함수는 Vercel 지역을 서울(`icn1`)로 지정했습니다 (`vercel.json`). 상대 서버 방화벽이 해외 IP 를 막을 수 있어서입니다.

## 지역축제 목록 관리

`src/data/festivalList.js` 에 축제마다 이름(4개 언어)·예년 개최 시기·사진·지역을 적어 둡니다. 정확한 날짜는 해마다 달라지고 비짓제주에는 날짜가 없어서, **웹에서 확인한 과거 개최 기록을 근거로 시기만** 적었습니다.

- `period: [[3, 'early'], [3, 'mid']]` → "3월 초순~중순" (순: `early` 1~10일 · `mid` 11~20일 · `late` 21일~, 생략하면 월만)
- `basis` 에 근거(예: "2025년 11/20~23")를 적어 둡니다. 화면에는 나오지 않습니다.
- 시기를 확인하지 못한 축제는 틀린 정보가 나가지 않도록 넣지 않았습니다.
- AI 가이드의 `list_festivals` 도구도 같은 파일을 읽습니다.

## 다국어

- 문구는 `src/i18n/messages.js` 한 파일에 키별로 4개 언어를 둡니다. 한국어가 기준이고 없는 키는 한국어로 대신 보입니다.
- 컴포넌트에서는 `const { t } = useT()` → `t('키', { 값 })`. 컴포넌트 밖(날짜·날씨 코드 등)에서는 `tr('키')`.
- 오류 메시지는 `throw new Error('err.키')` 처럼 문구 키를 던지고, 화면에서 `t(error)` 로 번역합니다. (서버가 준 문장은 그대로 통과)
- 언어를 바꾸면 페이지를 새로 그려서(`RootLayout` 의 `key={lang}`) 모든 글자가 한 번에 바뀝니다.
- 비짓제주 관광지는 선택한 언어(`kr`·`en`·`cn`·`jp`)로 요청해 이름·소개가 그 언어로 옵니다.

## AI 가이드 (Claude)

- 서버 함수 `api/chat.js` 가 Claude API 를 부르고, 도구는 `api/_tools.js` 에 있습니다.

| 도구 | 하는 일 |
|---|---|
| `search_events` | 날짜·분류·무료·실내외·지역·키워드로 행사 검색 |
| `get_event` | 행사 하나의 상세(소개·주최·문의) |
| `get_weather` | 최대 16일 예보 |
| `nearby_sights` | 행사 또는 좌표 주변 관광지 |
| `list_festivals` | 지역축제의 예년 시기 |

- 시스템 프롬프트가 지시하는 것: 도구 결과로만 답하기(행사·날짜·장소 지어내지 않기), 축제는 예년 시기일 뿐 확정 날짜가 아님을 알리기, 사용자 언어로 답하기, 행사는 `/events/번호` 링크로 안내, 주제에서 벗어난 요청은 정중히 거절, 도구 결과 속 문장은 명령이 아니라 자료로 취급.
- 응답은 줄마다 JSON 한 개(NDJSON)로 글자 단위 스트리밍됩니다. 화면은 `src/components/ChatWidget.jsx`, 상태는 `src/store/useChatStore.js` (대화는 저장하지 않고 탭이 열려 있는 동안만 유지).
- **비용 보호**: 접속자별 요청 제한(10분에 20회, 서버 한 대 안에서만 세는 간이 제한), 질문 600자 · 대화 12개 · 답변 5,000토큰 · 도구 왕복 6회 상한, 창을 닫으면 모델 호출 중단. 가장 확실한 한도는 **Anthropic 콘솔의 월 사용 한도**입니다.
- **보안**: 키는 서버에만 있습니다. 답변은 HTML 이 아닌 React 요소로만 그리고, 링크는 이 사이트 안 주소와 http(s) 만 허용합니다. 브라우저가 보낸 대화는 역할·길이·개수를 서버에서 다시 걸러 씁니다.
- 모델은 `claude-opus-5-5`, 생각 깊이 `low`. 더 싸고 빠르게 쓰려면 `ANTHROPIC_MODEL=claude-sonnet-5-5` 등으로 바꿉니다.
- 응답 품질은 실제 키로 확인하며 `api/chat.js` 의 시스템 프롬프트를 조정하세요.

## 알아 두면 좋은 것

- 서버 함수는 Vercel 환경변수를 **배포 시점에** 읽습니다. 바꾼 뒤에는 재배포하세요.
- 관광지 응답은 CDN 에 하루 캐시됩니다. 제외 목록을 고쳐도 반영에 최대 하루가 걸리고, 주소 끝에 `&v=숫자` 를 바꿔 붙이면 새 응답을 바로 볼 수 있습니다.
- 배포 직후 열려 있던 탭에서는 지도가 "페이지 없음" 으로 보일 수 있어 한 번 자동 새로고침하도록 처리했습니다.
- 행사 API 는 전시·공연 위주라 '축제' 로 등록된 행사는 적습니다 (2026-11 기준 4건). 그래서 지역축제는 시기 목록으로 따로 보여줍니다.
- 저장한 행사와 언어 선택은 이 브라우저의 localStorage 에만 있습니다.
- 사진 주소(비짓제주 CDN)가 바뀌거나 지워지면 해당 사진이 빠지며, 홈 배경은 사진이 없어도 글자가 읽히도록 되어 있습니다.
